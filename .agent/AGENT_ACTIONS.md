# Agent Actions

## Allowed Actions

- regenerate_statement
- regenerate_baseline
- rebuild_allocation_register
- open_internal_statement
- open_customer_statement
- open_baseline_report
- review_debtor
- approve_debtor
- mark_sent
- flag_dispute
- create_follow_up
- export_customer_output
- export_internal_output

## Rule

Every action must produce an audit event and update debtor state.
