# Source-session handoffs

Use [the session register](../README.md) to allocate and locate handoffs.

No historical handoffs have been imported at setup. Do not reconstruct them from memory and label them as full-session reviews.

Files use PD-SNNN_<stable-slug>.md and the nine sections in [the extraction prompt](../prompts/session-harvest.md). Store source conversation ID separately from collection ID. Keep one path per source session; revisions append a change log and preserve superseded material.

Before writing, follow [the saving prompt](../prompts/save-handoff.md), including the public-repository publication boundary.
